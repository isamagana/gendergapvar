# gendergapvar
gendergapvar is an open-source Python package built from scratch as part of my undergraduate Economics research. It replicates the methodology of Kovalenko & Töpfer (2021), estimating a structural vector autoregression (SVAR) with zero and sign restrictions on quarterly U.S. data from 1979–2019.

The package is designed to analyze how technology and wage-bargaining shocks affect the gender pay gap while providing a reproducible Python implementation of the underlying macroeconometric methodology.
